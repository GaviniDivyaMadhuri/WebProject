# 📖 Overview

Farmer's Friend is an AI-powered agriculture assistant designed to support farmers with real-time farming guidance using voice, text, and image-based interaction.

The platform helps farmers:
- Get crop and weather information
- Check market prices
- Detect plant diseases using images
- Receive voice-based AI responses in multiple languages

The application is designed with a simple and user-friendly interface suitable for rural and local farming communities.
