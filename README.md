🧑‍🌾 Farmer's Friend: AI-Powered Agricultural Assistant
Farmer's Friend is an inclusive, voice-enabled web application designed to empower farmers with real-time agricultural intelligence. Built using Google’s Gemini 2.5 Flash model, it bridges the gap between complex AI technology and rural accessibility by providing simple, actionable advice in local languages.

🚀 Key Features
🎤 Voice-First Interface: Integrated Speech-to-Text (STT) allows farmers to ask questions naturally without needing to type.

📸 AI Crop Doctor: Farmers can upload photos of diseased crops or leaves. The AI analyzes the image to identify pests or diseases and provides immediate organic/chemical solutions.

📈 Real-time Market Prices: Uses Google Search Grounding to provide the latest Mandi (market) prices based on the farmer's specific location.

🌍 Multilingual Support: Supports English, Hindi, Telugu, and Marathi to ensure language is never a barrier to expert advice.

🔊 Audio Responses: Features a Text-to-Speech (TTS) engine that reads out solutions, making the app accessible to users with varying literacy levels.

☀️ Local Weather & Tips: Provides context-aware weather updates and fertilizer recommendations.
